# 09 — Μαθήματα από Chatbots Ανταγωνιστών (Γενικά Patterns)

> Σκοπός: Για κάθε chatbot που μελετάμε στην αγορά, κρατάμε εδώ **μόνο τα γενικά,
> μεταφέρσιμα θετικά** — patterns που ισχύουν για οποιοδήποτε chatbot, ανεξαρτήτως
> κλάδου. Τίποτα ειδικό για τον κλάδο του κάθε πελάτη. Το αρχείο μεγαλώνει με κάθε
> νέα πηγή που εξετάζουμε.

---

## Πηγή #1 — BOX NOW · «Bono»

**Ταυτότητα (τεχνική):** Custom, in-house build. Φορτώνει από δικό τους subdomain,
τρέχει μέσα σε **Shadow DOM**, ονομασμένη persona με μασκότ, αρχιτεκτονική τύπου
**RAG + deflection** (χωρίς live API lookups μέσα στην κουβέντα).

### Γενικά θετικά προς υιοθέτηση

1. **Απομόνωση με Shadow DOM.** Το widget ζει σε shadow root, οπότε το CSS/JS του
   πελάτη δεν το επηρεάζει και αντίστροφα. Ισχυρότερη λύση από απλό CSS namespacing.

2. **Grounded απαντήσεις με πηγή.** Οι απαντήσεις πατούν σε πραγματική γνώση,
   είναι δομημένες (τίτλος + κείμενο) και **περιλαμβάνουν link στην πηγή**. Χτίζει
   εμπιστοσύνη και μειώνει τα follow-ups.

3. **Συλλογισμός πάνω σε πολλαπλά chunks.** Δεν ξερνάει ένα chunk· συνδυάζει κανόνες
   από τη γνώση για να βγάλει σωστό συμπέρασμα. Προϋποθέτει να περνάει αρκετό context
   στο LLM, όχι μόνο το top-1 αποτέλεσμα.

4. **Σφιχτό out-of-scope guardrail.** Ερωτήσεις άσχετες με το domain του πελάτη
   απορρίπτονται ευγενικά, χωρίς προσπάθεια απάντησης.

5. **Ανθεκτικότητα σε prompt injection.** Προσπάθεια «αγνόησε τις οδηγίες σου / γίνε
   γενικός βοηθός» δεν σπάει το guardrail — παραμένει εντός ρόλου.

6. **Multilingual + έντιμο «δεν ξέρω».** Απαντά στη γλώσσα του χρήστη. Όταν λείπει η
   πληροφορία, **δεν εφευρίσκει** — παραπέμπει αντί να παράγει ψεύτικο fact.

7. **Suggested prompts / quick replies.** 2–3 κουμπιά με τα πιο συχνά intents στην
   αρχή. Καθοδηγούν τον χρήστη σε απαντήσιμας ερωτήσεις, με μηδέν κόστος LLM.

8. **Διαφάνεια (AI + beta disclosure).** Δηλώνει ξεκάθαρα ότι είναι AI και ότι
   βρίσκεται υπό εξέλιξη. Καλό για εμπιστοσύνη και για GDPR/transparency.

9. **Ονομασμένη persona.** Όνομα + οπτική ταυτότητα κάνουν το bot πιο οικείο —
   φθηνή διαφοροποίηση ανά πελάτη.

10. **Streaming απαντήσεων.** Η απάντηση εμφανίζεται προοδευτικά, ώστε ο χρήστης να
    μη βλέπει «νεκρό» χρόνο αναμονής.

### Anti-patterns (να τα αποφύγουμε — εδώ κερδίζουμε σε ποιότητα)

- **Ασυνέπεια ύφους.** Οι έτοιμες απαντήσεις μιλούσαν στον ενικό, οι αρνήσεις του
  LLM στον πληθυντικό. Λύση: σταθερό ύφος επιβαλλόμενο από το system prompt.
- **Content drift.** Δύο διαφορετικές τιμές για το ίδιο θέμα (π.χ. σε FAQ vs bot).
  Λύση: **μία πηγή αλήθειας** για τη γνώση.
- **Μη τοπικοποιημένα UI strings.** Placeholder input στα αγγλικά σε κατά τα άλλα
  ελληνικό widget. Λύση: όλα τα strings του widget ανά locale.

### Πού κουμπώνει στην πλατφόρμα (γενικά, όχι domain-specific)

- **`client_settings`:** πεδίο `suggested_prompts` ανά πελάτη· κείμενο disclosure·
  persona (όνομα/χρώματα/λογότυπο)· σταθερό ύφος στο `system_prompt`.
- **`chat_service.py`:** επιστροφή `source_url` μαζί με την απάντηση· αρκετό context
  στο LLM για συλλογισμό· καθαρή out-of-scope / `is_unanswered` λογική· έντιμο «δεν
  ξέρω» αντί για hallucination.
- **`widget.js`:** εξέταση Shadow DOM για απομόνωση· streaming· τοπικοποίηση όλων
  των strings.
