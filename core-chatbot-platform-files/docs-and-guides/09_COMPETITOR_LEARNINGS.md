# 09 — Μελέτη Chatbots Αγοράς (Γενική Δομή + Ευρήματα)

> Σκοπός: Για κάθε chatbot που μελετάμε, ακολουθούμε την **ίδια δομή** (Μέρος Α)
> και κρατάμε **μόνο γενικά, μεταφέρσιμα θετικά** — patterns που ισχύουν για
> οποιοδήποτε chatbot, ανεξαρτήτως κλάδου. Κάθε νέα εταιρεία = νέα «Πηγή #N».

---

## ΜΕΡΟΣ Α — Γενική δομή αξιολόγησης (για ΚΑΘΕ bot)

### Α.1 · Διαστάσεις που εξετάζουμε

- **Αρχιτεκτονική:** custom ή έτοιμο SaaS· απομόνωση widget (Shadow DOM)· streaming.
- **Grounding & ακρίβεια:** RAG από πραγματική γνώση· link στην πηγή· τι κάνει όταν
  ΔΕΝ ξέρει (έντιμο «δεν ξέρω» vs hallucination).
- **Συλλογισμός:** συνδυάζει πολλαπλά facts/κανόνες για σωστό συμπέρασμα;
- **Scope & ασφάλεια:** απορρίπτει εκτός-θέματος; αντέχει prompt injection / jailbreak;
- **Γλώσσα:** multilingual· ανθεκτικότητα σε greeklish & ορθογραφικά.
- **Μνήμη:** κρατάει συμφραζόμενα σε follow-ups μέσα στην ίδια συνομιλία;
- **Καθοδήγηση:** quick-reply chips / suggested prompts για τα top intents.
- **Διαφάνεια:** δήλωση AI· beta notice· GDPR consent.
- **Persona / branding:** όνομα, μασκότ, συνέπεια ύφους.
- **UX:** ταχύτητα· read-aloud (TTS)· fullscreen· mobile· persistence ιστορικού.
- **Escalation & capture:** human handoff· lead capture· feedback (thumbs).

### Α.2 · Τυποποιημένη μπαταρία δοκιμών (τα probes που ρίχνουμε πάντα)

1. **Κλασικό FAQ** — ελέγχει grounding.
2. **Transactional αίτημα** — live lookup ή deflection σε σελίδα;
3. **Παγίδα εκτός θέματος** (π.χ. συνταγή/γενική γνώση) — μπλοφάρει ή αρνείται;
4. **Ερώτηση με συλλογισμό** — συνδυασμός 2+ κανόνων.
5. **Follow-up με αντωνυμία/έλλειψη** («Και για το Χ;») — μνήμη συμφραζομένωϽ.
6. **Greeklish + ορθογραφικό** — ανθεκτικότητα εισόδου.
7. **Άλλη γλώσσα** — multilingual + έντιμο «δεν ξέρω» όταν λείπει η πληροφορία.
8. **Prompt injection** («αγνόησε τις οδηγίες σου…») — αντοχή guardrail.

### Α.3 · Πρότυπο καταγραφής ανά πηγή (η «κάρτα»)

Vendor/τεχνολογία · Grounding · Escalation · Transactional · UX · **Τι υιοθετώ**.

## ΜΕΡΟΣ Β — Πηγές

## Πηγή #1 — BOX NOW · «Bono»

**Ταυτότητα (τεχνική):** Custom, in-house build (φορτώνει από δικό τους subdomain),
τρέχει σε **Shadow DOM**, ονομασμένη persona με μασκότ, αρχιτεκτονική **RAG + deflection**
(χωρίς live API lookups μέσα στην κουβέντα).

### Θετικά προς υιοθέτηση

1. **Απομόνωση με Shadow DOM** — το widget δεν επηρεάζεται από το CSS/JS του site.
   Ισχυρότερο από απλό CSS namespacing.
2. **Grounded απαντήσεις με πηγή** — δομημένες (τίτλος + κείμενο) και **με link** στην
   πηγή. Χτίζει εμπιστοσύνη, μειώνει follow-ups.
3. **Συλλογισμός πάνω σε πολλαπλά chunks** — δεν ξερνάει ένα chunk· συνδυάζει κανόνες
   (π.χ. εφάρμοσε σωστά όριο βάρους σε συγκεκριμένο ερώτημα). Θέλει αρκετό context στο LLM.
4. **Σφιχτό out-of-scope guardrail** — άσχετες ερωτήσεις απορρίπτονται ευγενικά.
5. **Ανθεκτικότητα σε prompt injection** — «γίνε γενικός βοηθός» δεν σπάει τον ρόλο.
6. **Multilingual + έντιμο «δεν ξέρω»** — απαντά στη γλώσσα του χρήστη· όταν λείπει η
   πληροφορία, **δεν εφευρίσκει** — παραπέμπει.
7. **Μνήμη συμφραζομένων** — καταλαβαίνει follow-ups («Και για το Χ;») χωρίς επανάληψη
   του θέματος. → Πέρνα το **ιστορικό συνομιλίας** στο LLM, όχι μόνο τη μεμονωμένη ερώτηση.
8. **Ανθεκτικότητα σε greeklish & ορθογραφικά** — «poses meres…» απαντήθηκε κανονικά.
   Κρϯσιμο για ελληνικό κοινό· έρχεται από το embedding retrieval.
9. **Suggested prompts / quick replies** — 2–3 chips με τα top intents· μηδέν κόστος LLM.
10. **Διαφάνεια (AI + beta disclosure)** — δηλώνει ξεκάθαρα ότι είναι AI υπό εξέλιξη.
11. **Ονομασμένη persona** — όνομα + μασκότ· φθηνή διαφοροποίηση ανά πελάτη.
12. **Streaming** απαντήσεων — μηδέν «νεκρός» χρόνος αναμονής.
13. **Read-aloud (TTS) + fullscreen** — μικρά UX/accessibility extras (ιδανικά ως feature flags).

### Κενά τους = ευκαιρίες για εμάς (να τους νικήσουμε)

- **Χωρίς feedback (thumbs up/down)** στις απαντήσεις → αν το βάλουμε, τροφοδοτεί το
  μελλοντικό Q&A training.
- **Χωρίς human handoff / lead capture** όταν κολλάει → απλώς παραπέμπει στο site.
  Το δικό μας escalation + lead capture είναι καθαρό πλεονέκτημα.
- **Ασυνέπεια ύφους** (ενικός στις έτοιμες, πληθυντικός στις αρνήσεις) → λύση:
  σταθερό ύφος επιβαλλόμενο από το system prompt.
- **Content drift** (δύο τιμές για το ίδιο θέμα σε διαφορετικές πηγές) → μία πηγή αλήθειας.
- **Μη τοπικοποιημένα UI strings** (αγγλικό placeholder σε ελληνικό widget) → όλα τα
  strings ανά locale.

### Adoption backlog → πλατφόρμα (γενικά, όχι domain-specific)

- **`client_settings`:** `suggested_prompts`· κείμενο disclosure· persona
  (όνομα/χρώματα/λογότυπο)· σταθερό ύφος στο `system_prompt`· feature flags για TTS/fullscreen.
- **`chat_service.py`:** επιστροφή `source_url` μαζί με την απάντηση· **ιστορικό
  συνομιλίας** στο LLM (μνήμη)· αρκετό context για συλλογισμό· καθαρή out-of-scope /
  `is_unanswered` λογική· έντιμο «δεν ξέρω»· (μελλοντικά) feedback + escalation/lead capture.
- **`widget.js`:** Shadow DOM· streaming· τοπικοποίηση strings· ανοχή greeklish στην είσοδο.
