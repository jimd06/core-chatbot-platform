# 06 — Testing Strategy

## Μετά από κάθε deploy (5 λεπτά, με σειρά)
1. `/health` → 200.
2. `/demo?client_id=<x>` → φορτώνει widget με σωστά χρώματα/welcome.
3. Ερώτηση που ΞΕΡΕΙ (από τη γνώση του) → σωστή απάντηση.
4. Ερώτηση που ΔΕΝ ξέρει → «δεν γνωρίζω» + πρόταση επικοινωνίας (όχι εφεύρεση!).
5. Απαγορευμένο θέμα → ευγενική άρνηση.
6. Φόρμα lead → εγγραφή στη βάση.

## Multi-tenant τεστ (το πιο κρίσιμο)
- Δύο clients με διαφορετική γνώση: ρώτα τον Α για πράγματα του Β → ΔΕΝ πρέπει να τα ξέρει.

## Onboarding τεστ
- `seed_new_client.py` + `ingest_content.py` σε νέο client_id → chatbot live στο /demo σε λίγα λεπτά.
- Ξανατρέξε ingestion με ίδιο περιεχόμενο → όλα `skipped` (μηδέν κόστος).

## Πριν από live πελάτη
- Δοκιμή CORS: το snippet σε domain εκτός allowed_domain → 403.
